# Release Notes - Version 1.0.0 (RC1)

- **Release Date**: July 27, 2026
- **Status**: Release Candidate (RC1)
- **Target Institution**: National Forensic Science University (NFSU)

---

## 1. What's New in v1.0.0

The ISCMS platform is fully optimized for institutional compliance tracking:

*   **Student Portal**: Passwordless OTP authentication and secure uploads.
*   **Reminder Engine**: Automates warning alerts (30, 15, 7, 3, 1 day) exclusively for eFRRO expirations.
*   **Production Gateways**: Integrations with Resend Email APIs and Meta WhatsApp Business Cloud APIs.
*   **Branding & Settings**: Centralized administrator branding settings (logos, support details, accents).
*   **System Diagnostics**: Interactive operations dashboard with active uptime probes (`/health`, `/readiness`, `/liveness`).
*   **Storage Retention Policy**: Automatic physical purges of files 30 days post-approval, preserving all database metadata.
